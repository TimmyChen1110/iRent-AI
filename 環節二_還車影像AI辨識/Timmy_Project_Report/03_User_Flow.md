# 使用者流程

## 租客（一般用戶）
```
還車 → App 引導拍 6 張照（4 方位 + 前/後車內）
→ 上傳即完成還車（AI 判定非同步，不用等）
→ 無異常：無感通過，車輛乾淨可回饋信譽加分
→ 有疑慮：收到補拍推播（照片沒拍到部位時）
→ 有爭議：索賠通知附借/還對照照片證據，透明有依據
```

## 站點 / 清潔調度
```
車內判定「髒汙」→ P1 即時通知
→ 該車暫停派單 → 優先清潔 → 完成後恢復
（下一位用戶不再拿到髒車）
```

## 客服 / 複核人員（Demo 主角）
```
開啟複核後台 → KPI 總覽（待複核 / P1 / P2）
→ 佇列依等級排序，紅橙綠色條一眼分流
→ 點開案件：借車照 vs 還車照並排
→ 讀 AI 判定卡：損傷位置/類型/嚴重度/信心 + 判定理由
→ 一鍵裁決：
   ✓ 確認車損 → 自動帶照片證據鏈進索賠
   ✕ 駁回誤報 → 回寫為訓練樣本
   ⟳ 要求補件 → 推播用戶補拍
→ 鍵盤 ↑↓/1/2/3 快速操作，秒級處理一件
```

## 營運管理層
```
Dashboard 看趨勢：預警量 / 複核結果 / 誤報率
→ 每次複核累積標註 → 模型持續變準 → 人工複核量遞減
```
