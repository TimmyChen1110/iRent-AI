**1.（標題頁）iRent 智能車況管家**
運用 AI 辨識還車影像 — 新車損偵測 × 車內整潔分級 × 後台預警

**2. 還車之後，發生了什麼？**
- 兩日 27,367 張還車照、4,820 筆訂單
- 照片只存檔，車損爭議靠人工翻圖
- 左後/右後漏拍率 25–30%
- 欄位官方註記：「上傳分類（常有誤）」

**3. 解決方案：智能車況管家**
- 借/還照比對 → 新車損預警
- 車內照 → 髒汙・普通・乾淨
- 異常分級：P1 即時／P2 工單
- 人工複核回寫，越用越準

**4. 系統架構**
- 既有鏈路零侵入：App → Blob → 事件觸發
- CV 前處理：EXIF 轉正・品質檢核
- 級聯判定：Flash 快篩 → Pro 複核
- 結構化 JSON → 預警引擎

**5. 為什麼是 VLM，不是傳統 CV？**
- 實測 141 組：CV 對齊成功率僅 45%
- 差異分數正負樣本完全重疊
- VLM 分得出「刮痕」vs「反光雨漬」
- 零訓練資料即可上線

**6. 實測結果｜141 組真實配對**
- 召回率：快篩 81% → 級聯複核 86%
- 全量重標後：召回 95.5%、誤報 0%
- 判定穩定性 99.3%
- API 成本 $0（免費額度完成）

**6b. 車內整潔實測｜80 張真實車內照**
- 髒汙檢出 3 張（3.75%），人工看圖確認
- Pro 複核救回快篩漏判的遺留垃圾
- 另抓到「車內照欄位混入車外照」
- 乾淨 21・普通 56・髒汙 3

**7. AI 抓到人漏掉的車損**
- 「未索賠」樣本中發現真實新損
- 借車照乾淨 → 還車照藍色擦痕
- 信心 0.98，附判定理由
- 不只省人力，還挽回漏損

**8. 複核後台 Demo**
- 借/還並排 + AI 標註理由
- P1 預警・P2 工單・P3 記錄
- 一鍵確認 → 自動進索賠
- 每次複核回寫為訓練資料

**9. 遇到的困難**
- 手持拍攝：角度光線落差極大
- 76% 照片 EXIF 方向錯置
- 標籤噪音：未索賠 ≠ 無車損
- 漏抓主因：損傷部位未入鏡

**10. 未來方向**
- App 拍攝端即時角度檢核
- 車輛照片鏈基準 → 召回 ≥90%
- 車內整潔 300 張標註校準
- 複核資料 → 自建輕量模型

**11. 成本與效益**
- 每單判定成本 < NT$1
- 全量上線約 NT$1,200／日
- 取代人工逐單翻圖
- 挽回未索賠漏損

**12. 結論**
- 零訓練・真實資料驗證
- 重標後 95.5% 召回・0 誤報・$0 原型
- 讓每一次還車，都被看見
