# 報告故事線（10 分鐘版）

1. **問題背景**（1.5 分）— 兩天 27,367 張還車照沒人看：車損爭議靠人工翻圖、後方漏拍 25–30%、髒車直接流轉。
2. **為什麼要做**（1 分）— 責任認定不透明傷用戶信任；人力抽查無法規模化；照片其實都在，只缺「會看照片的系統」。
3. **系統核心功能**（1 分）— F1 借/還比對抓新車損、F2 車內整潔三級分級、F3 分級預警 + 複核閉環。
4. **技術架構**（1.5 分）— 既有鏈路零侵入；CV 前處理 + VLM 級聯（Flash 快篩 → Pro 複核）；Structured JSON。
5. **實測結果**（2 分，重頭戲）— 141 組真實配對：Recall 85.7%／誤報 3.3%（原始索賠標籤）；人工重標後 Recall 100%／誤報 0.85%（n=137）。成本不作宣稱。兩個故事：AI 抓到未索賠真車損（conf 0.98）；CV 方案被自己的實驗推翻後改級聯。
6. **Demo**（2 分）— 複核後台實際操作（見 06_Demo_Script.md）。
7. **困難與未來**（1 分）— 手持拍攝品質是天花板 → 拍攝端即時檢核；Pro 複核補召回至 ≥90%。
8. **結論**（0.5 分）— 零訓練、真實資料驗證、每單不到 NT$1，讓每一次還車都被看見。
